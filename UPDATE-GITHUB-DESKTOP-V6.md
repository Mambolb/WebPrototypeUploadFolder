# Portfolio V6: GitHub Desktop update

**Current repository:** `Mambolb/WebPrototypeUploadFolder` (or the repository you actually publish).

1. In GitHub Desktop, choose the published repository and click **Repository → Show in Finder**.
2. Copy the entire repository folder somewhere else as a backup, outside the Git checkout.
3. Download **portfolio-v6-update-only.zip** (or use the full ZIP for fresh installation), unzip it, and copy **the contents of the unzipped folder** into the repository ROOT. Confirm **Replace** for `index.html`, `home.js`, `home.css`, `scenes.js`, `presentation-rules.js`, `irl-glitch.js`, `irl-glitch.css`, and `projects-data.js`.
4. The new image must end up in `assets/irl-home-background.png`. **Merge the `assets` folder**, do not delete all old media.
5. Open the site locally in VS Code with Live Server and test Digital Garden / Shahed / Mail / Instagram. Confirm all 8 links still work.
6. In GitHub Desktop's **Changes**, review changed files. Enter summary `Portfolio V6 – updated Figma desktop layout + hover` and click **Commit to main**.
7. Click **Push origin**. You don't need to create a new repository or configure Pages again.
8. Once deployment succeeds, hard-refresh the URL with `Cmd + Shift + R` or open a private window if the old version remains cached.

For large media files, use GitHub Desktop (not the GitHub website browser uploader). This update adds no new videos and does not recompress existing media.
